# Probabilidad en Python

Colección de notebooks y material de apoyo para practicar conceptos de probabilidad mediante Python.

## Contenido
Incluye ejercicios de cálculo de probabilidades, distribuciones, muestreo, simulación, distribución normal, variación muestral y procesos probabilísticos, además de material teórico sobre sucesiones de variables aleatorias y Teorema Central del Límite.

## Uso
Abre los archivos `.ipynb` en Jupyter Notebook o Google Colab y ejecuta las celdas en orden. Algunos resultados cambian entre ejecuciones porque utilizan simulación aleatoria.
